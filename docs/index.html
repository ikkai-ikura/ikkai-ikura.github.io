TANKAの比べ方

  1. 楽天市場から毎朝取得人気の商品の価格・レビュー数・評価を自動で集めます
  2. 内容量で割って単価にする「150個入×3袋」なども商品名から読み取って計算します
  3. 同じ商品は最安だけ掲載ショップ違い・袋数違いをまとめ、いちばん安い出品を表示します
  4. あなたのポイントで実質価格に楽天のポイント倍率（SPU）を選ぶと、ショップのポイントアップも足して実質の単価を出します
このサイトについて（計算方法・広告について）価格は取得時点のものです。購入前に商品ページで確認してください。
